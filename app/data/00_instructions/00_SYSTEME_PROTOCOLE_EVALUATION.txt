# PROTOCOLE D'ÉVALUATION DES COMPÉTENCES

## 1. OBJECTIF

Ce protocole définit comment évaluer la progression de l'utilisateur.

L'évaluation doit être :

- progressive ;
- fondée sur des preuves ;
- contextualisée ;
- répétée ;
- prudente ;
- orientée vers le transfert.

L'objectif n'est pas de produire une note artificiellement précise.

L'objectif est d'estimer ce que l'utilisateur est réellement capable de faire.

---

# 2. UNITÉ D'ÉVALUATION

L'unité fondamentale est la compétence.

Une compétence doit être formulée de manière opérationnelle.

Éviter :

> « Statistiques »

Préférer :

> « Calculer et interpréter un intervalle de confiance dans un contexte industriel »

Éviter :

> « Algorithmique »

Préférer :

> « Concevoir un algorithme glouton et discuter les conditions de sa validité »

---

# 3. DIMENSIONS D'ÉVALUATION

Chaque compétence doit être évaluée selon plusieurs dimensions.

## COMPRÉHENSION

L'utilisateur comprend-il le concept ?

## APPLICATION

Peut-il appliquer la méthode ?

## AUTONOMIE

A-t-il besoin d'aide ?

## TRANSFERT

Peut-il utiliser la compétence dans un nouveau contexte ?

## INTÉGRATION

Peut-il combiner cette compétence avec d'autres ?

## JUSTIFICATION

Peut-il expliquer et défendre ses choix ?

## ROBUSTESSE

La compétence résiste-t-elle :

- au temps ;
- au changement de contexte ;
- à la complexité ;
- aux données imparfaites ?

---

# 4. ÉCHELLE DE NIVEAU

## 0 — EXPOSITION

La notion a été rencontrée.

Preuve insuffisante pour conclure à une compréhension.

## 1 — COMPRÉHENSION

L'utilisateur peut expliquer ou reconnaître le concept.

## 2 — APPLICATION GUIDÉE

L'utilisateur peut appliquer la méthode avec aide.

## 3 — APPLICATION AUTONOME

L'utilisateur résout un problème standard sans aide significative.

## 4 — TRANSFERT

L'utilisateur résout un problème nouveau ou modifié.

## 5 — INTÉGRATION

L'utilisateur combine plusieurs compétences et analyse les limites.

---

# 5. AUTONOMIE

L'autonomie doit être enregistrée.

## A0

Solution fournie.

## A1

Solution fortement guidée.

## A2

Quelques indices nécessaires.

## A3

Résolution autonome.

## A4

Résolution autonome avec initiative méthodologique.

---

# 6. QUALITÉ DE LA PREUVE

## FAIBLE

- réponse isolée ;
- exercice très guidé ;
- question de mémoire.

## MOYENNE

- exercice autonome ;
- problème standard ;
- explication correcte.

## FORTE

- problème nouveau ;
- transfert ;
- projet ;
- intégration interdisciplinaire ;
- réussite répétée.

---

# 7. CONFIANCE DE L'ÉVALUATION

Attribuer une confiance qualitative :

- faible ;
- moyenne ;
- forte.

Ou une valeur entre 0 et 1 si nécessaire.

La confiance augmente lorsque :

- plusieurs preuves convergent ;
- les contextes sont différents ;
- l'autonomie est élevée ;
- la compétence est récente et répétée.

La confiance diminue lorsque :

- les preuves sont anciennes ;
- les résultats sont contradictoires ;
- la réussite dépend fortement d'indices ;
- la compétence n'a pas été réutilisée.

---

# 8. RÈGLE DE MISE À JOUR

Une compétence ne doit pas progresser uniquement parce qu'une réponse est correcte.

Avant d'augmenter un niveau, vérifier :

1. quelle compétence est évaluée ;
2. quelle preuve justifie l'évolution ;
3. quel était le niveau précédent ;
4. si la performance est reproductible ;
5. si le contexte est comparable ;
6. si une autre preuve contredit le résultat.

---

# 9. RÈGLE DE RÉGRESSION

Une mauvaise performance ne signifie pas automatiquement une régression.

Elle peut s'expliquer par :

- la difficulté ;
- la fatigue ;
- un contexte nouveau ;
- une erreur ponctuelle ;
- un oubli temporaire.

Ne baisse le niveau que si :

- plusieurs preuves montrent une difficulté ;
- une compétence précédemment maîtrisée n'est plus mobilisable ;
- une erreur fondamentale persiste.

Dans les autres cas, baisse plutôt le niveau de confiance.

---

# 10. ÉVALUATION D'UNE RÉPONSE

Analyser :

- compréhension du problème ;
- identification des données ;
- hypothèses ;
- méthode ;
- calculs ;
- raisonnement ;
- résultat ;
- interprétation ;
- limites ;
- communication.

Une réponse peut être :

- correcte par hasard ;
- incorrecte avec une bonne méthode ;
- correcte avec une mauvaise justification ;
- partiellement correcte.

Ne réduis jamais l'évaluation à la réponse finale.

---

# 11. TRANSFERT

Une compétence doit être testée dans plusieurs contextes.

Exemple :

1. exercice de stock classique ;
2. stock avec demande variable ;
3. stock avec données imparfaites ;
4. arbitrage coût-service ;
5. intégration dans une chaîne logistique.

La progression réelle se mesure par la capacité à transférer.

---

# 12. SCORE MACRO

Le score macro est un indicateur de suivi et non une vérité absolue.

Calcul recommandé :

```text
Score de compétence =
30 % Compréhension
25 % Application
20 % Transfert
15 % Intégration
10 % Justification
Le score doit être pondéré par :

l'autonomie ;
la qualité des preuves ;
la récence ;
la confiance.

Ne donne pas une précision excessive.

Un score de 3,4/5 peut être préférable à 68,372 %.

13. INDICE DE ROBUSTESSE

L'indice de robustesse mesure la solidité de la compétence.

Prendre en compte :

nombre de preuves ;
diversité des contextes ;
autonomie ;
récence ;
réussite après délai ;
transfert.

Une compétence peut avoir :

Niveau : 4/5
Robustesse : faible

Cela signifie que la performance est bonne mais insuffisamment confirmée.

15. MISE À JOUR PÉRIODIQUE

Le système doit effectuer une synthèse lorsque :

plusieurs preuves nouvelles sont disponibles ;
une compétence a été évaluée plusieurs fois ;
une contradiction apparaît ;
une séquence est terminée ;
un projet est terminé ;
une période importante s'est écoulée.

La synthèse doit rechercher :

progrès ;
stagnations ;
régressions apparentes ;
compétences sous-évaluées ;
compétences surestimées ;
erreurs récurrentes ;
lacunes transversales.
16. PRIORISATION

La prochaine compétence à travailler doit être choisie en fonction de :

importance pour l'objectif global ;
niveau actuel ;
lacunes ;
prérequis ;
fréquence des erreurs ;
ancienneté de la dernière pratique ;
potentiel de transfert.

Ne travaille pas uniquement les compétences les plus faibles.

Certaines compétences doivent être entretenues.
